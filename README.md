## 快速开始

### 环境要求

- Node.js 
- pnpm

### 安装依赖

```bash
pnpm install
```

### 启动开发服务器

```bash
pnpm run dev
```

访问 http://localhost:8000 查看演示。

### 构建生产版本

```bash
pnpm run build
```

## 项目结构

```
src/
├── pages/          # 页面组件
├── layouts/         # 布局组件
├── assets/          # 静态资源
└── global.css       # 全局样式
```

## 部署

构建后的静态文件位于 `dist/` 目录，可直接部署到任何静态文件服务器。
